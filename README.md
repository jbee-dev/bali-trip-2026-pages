# 발리와 길리 여행

- [웹 일정표](https://jbee-dev.github.io/bali-trip-2026-pages/plan.html#days)
- [현재 준비 목록](preparation.md): 체크리스트 v15에서 생성한 숙소·교통·입국 서류·남은 예약.

홈 화면 아이콘: 야자수·발리 사원·파도 라인아트. `plan.html`과 루트 진입 페이지에 iOS 홈 화면 아이콘·파비콘·웹 앱 manifest를 연결했습니다. 홈 화면 이름은 ‘발리 여행’이며 열면 날짜별 일정으로 이동합니다. 일정 조회에는 인터넷 연결이 필요합니다.

9/8 업데이트: 아이온 발리 베노아 9/27~28 1박과 클룩 아융강 래프팅 10/6 예약 완료를 사용자 전달 기준으로 반영했습니다. 아이온 1박 USD 23.85와 래프팅 USD 84.88·10/6 오전 출발은 사용자 전달 기준입니다. 호텔 객실·조식·취소 조건·세금 포함 여부·확정서와 래프팅 정확한 시각·운영사·인원·픽업·취소 조건·바우처, 실제 결제 내역은 미확인입니다.

길리 에어 9/28~10/1 3박, 카사 카이 10/1~3 2박을 유지하고 펄 선셋 10/3~5 2박과 페르티위 비스마 우붓 10/5~7 2박을 반영했습니다. 시데멘은 현재 일정에서 제외했고, 라구나 10/7~9 기존 예약은 유지합니다.

새 숙소는 사용자 예약 완료 전달 기준입니다. 펄 선셋은 세금 포함 USD 218.99, 페르티위는 USD 78.62로 4박 합계 USD 297.61입니다. 확정서·객실·조식·취소 조건과 페르티위의 정확한 지점·세금 포함 여부는 확인 전이며 캐시백은 차감하지 않았습니다.

KTMB 9/26 07:30 출발·22:30 귀환과 에카자야 9/28 출발편은 발권 확인 기록을 유지합니다. 10/5 길리 귀환 배는 신청 전이며 차량도 미예약입니다. 아이온에서는 9/28 06:15 출발 제안 → 06:30 체크인 → 07:30 출항으로 준비합니다. 이전 숙박 비교안은 과거 기록으로 구분했습니다.

개인 예약번호·여권·입장 QR과 개별 티켓은 공개하지 않습니다. 준비 목록은 개인 보관 정본에서 생성하며 생성물을 다음 입력으로 사용하지 않습니다.
