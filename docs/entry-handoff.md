# 입국 신고 이어서 하기

2026년 9월 23일 새벽 기준이야. 여행자 2명 모두 같은 일정으로 이동해.

## 완료한 것

| 항목 | 상태 | 확인한 근거 |
| --- | --- | --- |
| 9월 24일 말레이시아 최초 입국 MDAC | 완료 | 사용자가 완료했다고 확인했어. |
| 인도네시아 관광비자 | 두 사람 모두 승인 | 각 사람의 승인 메일과 PDF 첨부를 확인했어. |
| 9월 25일 싱가포르 SGAC | 두 사람 모두 접수 완료 | 공식 성공 화면, 각각의 DE 번호, 두 사람 확인서 PDF를 확인했어. |
| 싱가포르 25일 접수 확인서 보관 | 이메일 발송 완료 | 보관용 메일에 두 사람 PDF를 첨부해 보냈어. |
| 9월 26일 왕복 기차표 | 예매 완료 | 사용자가 완료했다고 확인했어. 새로 예약할 필요 없어. |

보관용 메일은 제목에 `[여행 보관용] 2026년 9월 25일 싱가포르 입국 신고 확인서`가 들어 있어. 회사 컴퓨터에서는 해당 메일의 첨부파일을 내려받으면 돼. 정부에서 보내는 SGAC 자동 확인 메일은 마지막 검색 당시 아직 찾지 못했지만, 공식 사이트 접수는 성공했어.

## 남은 신고

| 신고 | 입국일 | 출국일 | 이동 및 상태 |
| --- | --- | --- | --- |
| 말레이시아 MDAC | 9월 25일 | 9월 26일 | 싱가포르에서 버스로 돌아와. 두 사람 모두 미제출이야. |
| 말레이시아 MDAC | 9월 26일 | 9월 27일 | 싱가포르에서 기차로 돌아와. 두 사람 모두 미제출이야. |
| 싱가포르 SGAC | 9월 26일 | 9월 26일 | 기차 당일치기야. 두 사람 모두 미제출이야. |
| All Indonesia | 9월 27일 | 예약 항공권으로 확인 | 발리 입국용이야. 두 사람 모두 미제출이야. |

25일과 26일 모두 싱가포르에 갔다가 자정 전에 조호르바루로 돌아오는 일정이야. 말레이시아 마지막 출국은 27일이지만, **25일 재입국 신고의 출국일은 다음 국경 이동일인 26일**로 넣어야 해.

23일 새벽 MDAC 공식 화면에는 제출일 포함 3일 이내라고 안내됐지만, 새로 연 화면에서도 25일은 비활성화돼 있었어. 원인은 확인되지 않았어. 작성 중인 화면은 집 컴퓨터에 남겼고, 제출은 하지 않았어. 다시 시작할 때 실제 선택 가능한 날짜부터 확인해. 날짜 제한을 우회하거나 다른 날짜로 대신 제출하지 마.

26일 SGAC는 24일부터, 27일 All Indonesia는 24일부터 진행할 예정이야. 해당 날짜에 공식 화면의 접수 가능 여부를 다시 확인해.

## 회사 컴퓨터에서 이어갈 순서

1. 이 저장소에서 `git pull --ff-only`로 최신 문서를 받아줘.
2. 집 컴퓨터의 예약 실행 결과와 받은 메일부터 확인해. 이미 접수번호가 생긴 사람·입국일은 다시 제출하지 마.
3. 아래 공식 사이트에 접속하고, 여권 원본·기존 비자·항공 및 기차 예약 메일을 열어줘. 브라우저 로그인, 작성 중인 화면, 로컬 파일과 예약 작업은 Git으로 옮겨지지 않아.
4. 위 표의 미완료 신고만 처리해. 기차 편명·시간과 숙소 상세주소는 실제 예약 메일을 사용해. 25일 버스 노선은 아직 미정이야.
5. 사람별 이름·여권·생년월일·만료일과 입출국 날짜를 원본과 대조해. 새 건강·세관 질문의 답을 추측하지 마.
6. 성공 화면과 사람별 접수번호를 확인한 뒤 PDF를 내려받아 사용자가 지정한 이메일로 보내줘. 이 문서에는 완료 상태만 갱신해.

SGAC는 차량번호를 모르는 버스 여행자의 경우 `BUS`, 기차 여행자의 경우 `TRAIN`으로 먼저 제출하고 실제 번호를 알게 되면 수정할 수 있다는 [ICA 공식 안내](https://ask.gov.sg/ica/questions/clos83fv8019j5k0wz0kommkm)가 있어. 말레이시아 신고에는 이 규칙을 그대로 적용하지 말고 별도로 확인해.

## 집 컴퓨터의 예약 실행

- 2026년 9월 24일 오전 9시, 중국·말레이시아·싱가포르 시간(UTC+8)에 이 작업을 이어가도록 예약했어.
- 예약 이름은 `여행 입국 신고 마무리`야. 회사에서 직접 진행할 경우 먼저 이 예약의 실행 상태를 확인해.
- 왕복 기차표는 예매 완료로 반영돼 있어. 남은 신고 처리와 확인서 이메일 발송이 예약에 들어 있어.
- 전원 연결 시 자동 절전을 5분에서 사용 안 함으로 바꿨어. 모든 신고가 끝나면 원래 5분 설정으로 복원하도록 예약에 적어뒀어. 수동 복원 명령은 `powercfg /change standby-timeout-ac 5`야.
- 잠금 상태에서는 브라우저 연결을 우선 사용하도록 했지만, 실제로 끝까지 작동하는지는 검증하지 못했어. Codex와 브라우저가 실행 중이고 인터넷이 연결돼 있어야 해.
- 사용자는 신고 작성·제출과 PDF 이메일 발송을 요청했어. 일반적인 진행 승인을 반복해서 묻지 마. 다만 도구가 실행 시점 확인을 요구하는 보안문자·법적 동의는 해당 규칙을 따라야 해.
